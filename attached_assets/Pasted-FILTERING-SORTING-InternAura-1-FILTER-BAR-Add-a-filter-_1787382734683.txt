FILTERING & SORTING — InternAura

1. FILTER BAR
- Add a filter bar/sheet accessible from the Dashboard (icon button opens a bottom 
  sheet or modal, not a separate screen).
- Filters available:
  - Domain (multi-select chips: AI/ML, Full Stack, Data Science, Marketing, Design, etc. 
    — derive options dynamically from distinct `domain` values in `internships`)
  - Work mode (single-select: Any / Remote / On-site / Hybrid)
  - Location (text search or dropdown of distinct `location` values)
  - Stipend range (min-max slider, based on `stipend` column)
  - Duration (single-select: Any / <1 month / 1-3 months / 3-6 months / 6+ months)
  - Minimum match % (slider, 0-100, filters on `recommendations.score`)

2. FILTER LOGIC
- Filters apply client-side on top of the already-fetched `recommendations` + 
  `internships` join — do NOT refetch from Supabase on every filter change; filter the 
  in-memory list for responsiveness.
- Multiple filters combine with AND logic (e.g. domain=AI/ML AND work_mode=Remote AND 
  match% >= 70).
- Show a live count: "Showing 12 of 45 internships" above the list as filters are 
  applied.
- Include a "Clear all filters" action, always visible when any filter is active.

3. SORTING
- Add a sort control (dropdown or segmented control) on the Dashboard with options:
  - Best Match (default — sort by `recommendations.score` descending)
  - Newest (by internship `created_at` if present, else skip this option)
  - Highest Stipend (by `stipend` descending)
  - Deadline/Duration (shortest duration first, optional)

4. SAVED FILTER STATE
- Persist the student's last-used filter/sort selection in AsyncStorage so it survives 
  app restarts and re-applies automatically on next dashboard load.

5. EMPTY STATE FOR FILTERS
- If filters result in zero matches, show a distinct empty state: "No internships match 
  these filters" with a "Clear filters" button — do not reuse the generic 
  no-recommendations empty state.

6. UI PLACEMENT
- Filter/sort controls should sit directly above the internship card list on the 
  Dashboard tab, collapsible into a compact bar with an active-filter-count badge 
  (e.g. "Filters (3)") when the sheet is closed.
